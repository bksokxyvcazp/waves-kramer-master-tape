## Overview

Waves Kramer Master Tape emulates a vintage 2-inch tape machine calibrated by legendary engineer Eddie Kramer, delivering tape saturation, compression, and frequency response coloration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves Kramer Master Tape** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Tape Speed** | 7.5, 15, and 30 IPS tape speed settings with different frequency responses |
| **Bias Control** | Adjustable bias from over-biased warmth to under-biased brightness |
| **Noise Level** | Adjustable tape hiss level for authentic vintage noise floor |
| **Eddie Calibration** | Calibrated to Eddie Kramer's personal tape machine preferences |
